# CODEVANTURE 기획 기준

## 프로젝트 이름과 목적

- 정식 작업명: **CODEVANTURE**
- 이전 가칭: 코티알피지
- 사용자가 직접 이동하며 이야기 속 문제를 코딩으로 해결하는 2D 횡스크롤 웹 TRPG
- 이야기를 따라가며 끝까지 클리어할 수 있는 게임

## 사용자와 정한 방향

### 시작 화면

- 흰색 배경에 어두운 입력창만 표시합니다.
- 문구는 `게임을 진행하려면 키를 입력하세요`입니다.
- 시작 키는 정확히 `Hello World;`이며 세미콜론을 포함합니다.
- 첫 화면에는 정답, 설명, 메뉴, 모드 선택을 추가하지 않습니다.
- 입력 성공 후 애니메이션으로 2D 월드가 나타납니다.

### 이동과 상호작용

- 사용자가 캐릭터를 직접 조작합니다.
- 탐험 중 NPC·장치·사건과 상호작용하고 필요한 순간 코딩합니다.
- 코딩의 결과가 게임 월드와 스토리 진행에 반영됩니다.

### 네 가지 모드

| 모드   | 방향                                               |
| ------ | -------------------------------------------------- |
| 쉬움   | 블록 코딩                                          |
| 중간   | 직접 코드 입력, 브론즈·실버 수준을 기준으로 구체화 |
| 어려움 | 중간보다 높은 알고리즘·문제 해결 난이도            |
| AI     | AI가 사용자를 대신해 코드를 작성                   |

## 아직 확정하지 않은 사항

- 상세 세계관, 캐릭터, 최종 스토리, 그래픽·사운드 스타일
- 정확한 이동·점프·상호작용 키와 모드 선택 시점
- 지원 코딩 언어: JavaScript 단일 언어가 초기 제안이며 확정 필요
- 코드 실행기와 지원 문법, 실행 시간·메모리·출력 제한
- 로그인 필수 여부, 저장 방식, 무료 AI 사용량과 대체 해법
- 첫 퀘스트와 전체 플레이 시간

## 초기 개발환경 범위

현재 화면은 환경 확인용 임시 화면입니다. 정식 게임 시작 화면이 아닙니다.
게임 기능은 구현하지 않았으며, 이후 작업에서 위 요구사항대로 교체합니다.

Netlify 기반 무료 배포를 우선 검토하고 AI·DB 사용량은 별도로 관리합니다.
현재 무료 한도, 모델 이름, 실제 운영 가능량은 이 문서에서 고정하지 않습니다.
