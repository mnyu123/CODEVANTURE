# CODEVANTURE 기획 기준

## 프로젝트 이름과 목적

- 정식 작업명: **CODEVANTURE**
- 이전 가칭: 코티알피지
- 사용자가 직접 이동하며 이야기 속 문제를 코딩으로 해결하는 2D 횡스크롤 웹 TRPG
- 이야기를 따라가며 끝까지 클리어할 수 있는 게임

## 사용자와 정한 방향

### 시작 화면

- 페이지 진입 시 먼저 쉬움·중간·어려움·AI 모드를 표시합니다. 기본 난이도를 자동 선택하지 않습니다.
- 실제 AI 연동 전에는 AI 모드를 준비 중으로 표시합니다.
- 난이도를 선택한 뒤 흰색 배경에 어두운 입력창을 표시합니다.
- 문구는 `게임을 진행하려면 키를 입력하세요`입니다.
- 시작 키는 정확히 `Hello World;`이며 세미콜론을 포함합니다.
- 키 입력 화면에는 정답이나 추가 메뉴를 표시하지 않습니다.
- 입력 성공 후 애니메이션으로 2D 월드가 나타납니다.

### 이동과 상호작용

- 사용자가 캐릭터를 직접 조작합니다.
- 모바일에서는 화면 버튼으로 이동·점프·조사하고, 중간 난이도는 블록과 직접 입력을 전환할 수 있습니다.
- 탐험 중 NPC·장치·사건과 상호작용하고 필요한 순간 코딩합니다.
- 코딩의 결과가 게임 월드와 스토리 진행에 반영됩니다.

### 네 가지 모드

| 모드   | 방향                                               |
| ------ | -------------------------------------------------- |
| 쉬움   | 블록 코딩                                          |
| 중간   | 직접 코드 입력, 브론즈·실버 수준을 기준으로 구체화 |
| 어려움 | 중간보다 높은 알고리즘·문제 해결 난이도            |
| AI     | AI가 사용자를 대신해 코드를 작성                   |

## 아직 확정하지 않은 사항

- 상세 세계관, 캐릭터, 최종 스토리, 그래픽·사운드 스타일
- 정확한 이동·점프·상호작용 키와 모드 선택 시점
- 지원 코딩 언어: C, C++, Java, Python, JavaScript로 확정. 현재 문제의 로컬 문법 지원 후 정식 실행기 연동
- 코드 실행기와 지원 문법, 실행 시간·메모리·출력 제한
- 로그인 필수 여부, 저장 방식, 무료 AI 사용량과 대체 해법
- 첫 퀘스트와 전체 플레이 시간

## 초기 개발환경 범위

잊힌 계곡의 관문을 열면 메아리 협곡, 청람 수로, 거울 온실, 별빛 관측소가 이어집니다.
1~4스테이지는 단순 계산에서 논리식, 나머지, 조건 분기로 차근차근 확장합니다.
5스테이지에서 배열을 도입하고, 코드 모드는 기준에 맞는 항목 세기와 가장 긴 연속 구간으로 나뉩니다.
문제에서 제공하는 값과 풀이 규칙을 코딩창의 안내 상자에 표시합니다.
정답이 제출되면 작성한 코드가 장치에 흡수되고, 그 결과로 관문이나 수문이 열리거나 다리 발판이 이어집니다.
AI 연결·로그인·저장은 후속 작업입니다.

Netlify 기반 무료 배포를 우선 검토하고 AI·DB 사용량은 별도로 관리합니다.
현재 무료 한도, 모델 이름, 실제 운영 가능량은 이 문서에서 고정하지 않습니다.
