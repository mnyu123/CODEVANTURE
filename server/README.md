# Server

Netlify 함수에서 호출할 서버 전용 AI·저장·인증 로직을 구현할 위치입니다.
현재 외부 API 요청, DB 연결, 실제 인증 처리는 없습니다.

- 브라우저의 `src/`에서 이 디렉터리를 import하지 않습니다.
- Gemini 키는 서버 환경변수에만 두며 `VITE_` 접두사를 사용하지 않습니다.
- AI 제공처와 모델을 교체 가능한 구조로 두되 실제 연동 때 구현합니다.
- AI 요청은 인증, 사용량 제한, 입력 검증을 통과한 뒤 수행합니다.
- AI 응답의 형식과 크기를 검증하고 사용자 코드와 같은 판정을 거칩니다.
- timeout, 중복 요청, 취소, 제한된 재시도를 처리합니다.
- Supabase는 HTTP Data API부터 검토하며, 클라이언트 접근 시 RLS를 적용합니다.
- 함수 메모리를 영구 저장소나 전체 사용량 카운터로 사용하지 않습니다.
